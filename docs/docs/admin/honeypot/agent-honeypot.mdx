# AI Agent Honeypots

Many administrators have noticed AI agent traffic adding to the pile and overwhelming servers. What if agents could just tell you who their users are so you can send them polite emails asking them to adjust their life choices?

As of Anubis v1.28.0 or later, every page gets extra (hidden) information embedded to do just that. Clients that choose to not process CSS will see these instructions.

This will ban the user's IP address for an hour and result in additional `WARN` log entries with the information that user agents provide:

```json
{
  "time": "2026-08-28T19:42:51.64341217-04:00",
  "level": "WARN",
  ...
  "msg": "AI agent tried to bypass Anubis, banning them for an hour",
  ...
  "contact_information": {
    "email_address": "me@xeiaso.net",
    "agent_harness": "opencode",
    "model_name": "techaro/intelliga-mini",
    "operating_system": "linux",
    "git_real_name": "Xe Iaso"
  }
}
```

The IP ban will last for one hour and automatically expire when it is over. There is currently no way to forcibly remove this ban. If you end up in a circumstance where this becomes a problem, please consider locating the user responsible and arranging for another way to get them the information they require.
